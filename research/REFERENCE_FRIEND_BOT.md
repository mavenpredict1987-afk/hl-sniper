## 2. Механизмы, которых у нас нет

### 2.1. Непрерывный трейлинг (bot.py)
```python
if pos.partial_done:
    trail = price - pos.atr_at_entry * config.ATR_TRAIL_MULT   # 1.0
    pos.stop = max(pos.stop, trail)          # на каждом тике
```
**У нас** стоп двигается ОДИН раз к +0.5R и застывает. Отсюда «дошли до
+15.7% и отдали всё».

### 2.2. Выходы на каждом тике (ws_feed.py)
```python
mid = (bids[0][0] + asks[0][0]) / 2
self.bot.check_exits(symbol, mid)     # на каждом обновлении стакана
self.bot.on_ws_price(symbol, px)      # и на каждом принте сделки
```
У нас опрос раз в 5 секунд. Бэктест предполагает точный стоп — живьём
выходим с опозданием.

### 2.3. Тайм-стоп с продлением (scalper.py)
```python
if elapsed >= TIME_STOP and r_now >= 0.3:
    pos.extended = True            # +2 часа
    pos.stop = entry + 0.3*r_dist  # фиксируем +0.3R
```
«Не режем победителей по часам».

### 2.4. Авто-пауза после серии (bot.py)
```python
if consec_losses >= 2: loss_pause_until = now + 4h
```

### 2.5. Сброс сигналов при закрытии (bot.py)
```python
self.sniper.convergence.signals.pop(symbol, None)
```
Против мгновенного повторного входа по «свежим» сигналам.

### 2.6. Скальпер как вторая стратегия (scalper.py)
15m импульс: тело >0.6×ATR14 и объём >1.8× — вход только на ПЕРВОЙ свече
(вторая импульсная подряд = погоня). Стоп 0.8×ATR, фиксация 30% на +1R,
трейлинг 0.5×ATR, выход на разворотной свече. Риск 0.75%.
Динамический пул: топ-8 по объёму ≥$25M + импульс, пересборка раз в час.

## 3. Для реальных денег (из api_client.py)

- **EIP-712 подпись ордеров**: `_sign_l1_action` (msgpack + nonce + vault →
  keccak → phantom agent), `EIP712Domain`, `HyperliquidSignTransaction`
- **Decimal-округление**: ≤5 значащих цифр, ≤`6 − szDecimals` знаков;
  покупка вверх (ROUND_CEILING), продажа вниз (ROUND_FLOOR)
- **Биржевые reduce-only стопы** `tpsl:"sl"` вместо программных
- **Failure semantics**: `None` (ошибка API) против `{}` (нет позиций),
  `float_to_wire` бросает исключение вместо тихого округления
- Пост-мортем в комментариях: float-артефакты → биржа отклоняла закрытия →
  «фантом-цикл NEAR 29.09: 3 часа ретраев»
- Env: `HYPERLIQUID_ADDRESS`, `HYPERLIQUID_PRIVATE_KEY`, `HYPERLIQUID_VAULT_ADDRESS`

## 5. Открытый конфликт

**ATR_STOP_MULT.** Их 400-дневный grid search → 1.35 (как у нас).
Наш 208-дневный бэктест → 2.5 лучше по всем метрикам.

Гипотеза: у них `PARTIAL_RATIO = 0.3`, и с таким ведением узкий стоп может
работать иначе. **Разрешается матрицей прогонов**, не спором.

Матрица:
| Вариант | Шорты | Трейлинг | Фиксация | Стоп |
|---|---|---|---|---|
| A (текущий) | вкл | нет | 0.5 | 1.35 |
| B | **выкл** | нет | 0.5 | 1.35 |
| C | выкл | **да** | 0.3 | 1.35 |
| D | выкл | да | 0.3 | **2.5** |
